# Angular: “Build your first Angular app”

This is a faithful walkthrough of “[Build your first Angular app](https://angular.dev/tutorials/first-app).” The major difference here is that the Angular CLI (the `ng` command) is _not_ (and will never again) be installed globally on my desktop. This means `npx` (the Node Package eXecutor [📖 [docs](https://docs.npmjs.com/cli/v8/commands/npx)]) must precede all of my `ng` commands.
